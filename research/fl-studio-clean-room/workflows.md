# workflows.md — Пошаговые пользовательские сценарии FL Studio

12 сценариев в формате: **Исходное состояние → Действия → Реакция интерфейса → Изменения данных → Результат → Особые случаи**. Пометки: **[A]** официальный мануал/PDF/транскрипт, **[B]** сторонние гайды, **[C]** вывод. Полные источники — в `sources.md`.

---

## Сценарий 1. Создание нового проекта

**Исходное состояние.** FL Studio запущена. При первом старте — окно Welcome (недавние проекты, шаблоны) [A].

**Действия.**
1. FILE > New — новый проект из **последнего использованного шаблона**; FL предложит сохранить изменения текущего проекта [A]. FILE > New from template — выбрать шаблон (Genre/Minimal/Utility) [A].
2. По умолчанию загружается дефолтный шаблон; в Channel Rack уже лежат 4 канала — **Kick, Clap, Hat, Snare** [B: EDMProd, Production Den; согласуется с официальным уроком «Making a Beat in Channel Rack», построенным «based on the default FL Studio template» [A-частично]].
3. Дефолтный темп — **130 BPM** [B: официальный форум, сниппет; в прочитанных страницах мануала числа нет — уверенность средняя].

**Реакция интерфейса.** Виден тулбар + плавающие окна (Playlist, Channel Rack, Browser; по данным туториалов — также Piano Roll и Mixer доступны по F-клавишам) [B/A]. Статус — PAT mode, позиция 1:1 [C по совокупности].

**Изменения данных.** Создан пустой .flp: шаблон задаёт каналы, темп, раскладку окон [A].

**Результат.** Готовая «печная заготовка»: сразу можно набивать шаги.

**Особые случаи.** Startup project (Options > General): Empty / Default template / Last used — меняет поведение старта [A]. «Чистый» старт, который советуют гайды: New from template > Minimal > Basic + F12 (закрыть все окна) [B].

## Сценарий 2. Ударный паттерн через Step Sequencer

**Исходное состояние.** Новый проект, дефолтные каналы Kick/Clap/Hat/Snare, PAT mode, темп задан.

**Действия.**
1. Убедиться, что транспорт в **PAT** (иначе играет Playlist) [A].
2. **ЛКМ по клеткам** канала Kick: шаги 1, 5, 9, 13 — «четыре удара в такте». Клетка подсвечивается; при игре канал вспыхивает на активных шагах [A/PDF].
3. **ПКМ** — выключить шаг; можно вести мышью с зажатой кнопкой [A].
4. Снэр/хэт: заполнить свои шаги; для роллов — ПКМ по кнопке канала → **Fill each 2/4/8 steps** [A].
5. Крутить **Swing** на тулбаре rack — удлиняются нечётные 16-е (грув) [A]. Важно: работает, только если и Channel Swing > 0 (MISC-вкладка) [A].
6. Больше 16 шагов: потянуть **правый нижний угол rack** (до 512 шагов = 32 такта) или Pattern Length = Auto [A].

**Реакция интерфейса.** Шаги светятся; Space — паттерн играет циклически; имена каналов подсвечиваются при звуке [A/PDF].

**Изменения данных.** В паттерне у каждого канала появился bitset шагов (шаг = 16-я, **note-off у шагов нет** [A]).

**Результат.** Готовый 1–2 тактный луп; один паттерн = один «инструментальный слой» (совет гайдов: отдельный паттерн под партию) [B].

**Особые случаи.** Velocity шагов меняется в **Graph Editor (Ctrl+K)** — колонки над шагами [A]. Длинные сэмплы наслаиваются: ПКМ по каналу → **Cut self** — новая нота срезает предыдущую [A/PDF]. Копия партии в другой канал: выбрать канал, Ctrl+C, выбрать целевой, Ctrl+V [A]. Шаг без динамики «мёртвый» — туториалы советуют сразу вести velocity [B/A-PDF].

## Сценарий 3. Мелодия в Piano Roll

**Исходное состояние.** Есть паттерн и инструментальный канал (например, добавлен синт).

**Действия.**
1. ПКМ по кнопке канала → **Piano roll** (или клик по мини-роллу в rack; F7 — переключить окно) [A].
2. Рисование нот инструментом **Draw (P)**: ЛКМ — нота (длина = последней тронутой); drag — перенос; за правый край — растянуть; **ПКМ — удалить** [A].
3. **Snap**: сменить в snap-селекторе (Line подстраивается под зум); Alt — временно без привязки [A].
4. Тональность: ПКМ по **Snap to scale** — тоника+гамма; фон подсвечивает ноты гаммы; притягиваются ноты только при переносе [A].
5. Аккорд — инструмент **Stamp**; прогрессия — Chord Progression Tool (Alt+P) [A].
6. Velocity и др.: колонки в нижней панели; Alt+колесо над нотой — менять текущее свойство; двойной клик по ноте — диалог свойств [A].
7. Слайд (глиссандо): включить **Slide (S)**, нарисовать слайд-ноту, **перекрывающую** целевую — высота поедет к слайду; длительность перекрытия = время слайда [A].

**Реакция интерфейса.** Ноты звучат при постановке (preview); ghost-ноты других каналов показаны серым; канал в dropdown отмечен галочкой [A].

**Изменения данных.** В канал, в текущий паттерн, добавлен список нот {start, length, pitch, velocity, pan, release, modx, mody, цвет-группа} [A].

**Результат.** Мелодия/аккорды; в rack у канала вместо шагов — мини-превью ролла [A].

**Особые случаи.** Слайды работают **только с нативными инструментами**; для VST — автоматизация channel pitch [A]. Если шаги канала уже были — они появятся в ролле как ноты на C5 [A]. Паттерн можно.transpose целиком (PATTERNS > Transpose) [A].

## Сценарий 4. Добавление паттерна в Playlist

**Исходное состояние.** Паттерн(ы) готовы; Playlist открыт (F5); режим инструментов — Draw/Pencil.

**Действия.**
1. В **Picker Panel** слева выбрать паттерн (или выбрать его в Pattern Selector тулбара) [A].
2. ЛКМ по пустому месту трека — Pattern Clip поставлен в позицию сетки; drag — двигать до отпускания [A].
3. Включить **SONG mode** (L) и Space — играет аранжировка [A].

**Реакция интерфейса.** Клип отображает мини-содержимое паттерна (ноты/события слоями); playhead бежит по Playlist; при достижении конца данных/Loop-маркера — возврат [A].

**Изменения данных.** В аранжировке: {трек, позиция, клип → паттерн N}. Данные паттерна не копируются — клип ссылка [C по поведению Make unique: независимая копия создаётся только ею — A].

**Результат.** Начало аранжировки; секции добавляются последующими паттернами (типовой процесс: F4 — новый пустой паттерн под секцию) [A/B].

**Особые случаи.** Snap влияет на позицию клипа (Line — обычно лучший) [A/PDF]. Клипы можно накладывать (полупрозрачность) — «даже на одном треке» [A].

## Сценарий 5. Дублирование, перемещение, обрезка, удаление клипов

**Исходное состояние.** В Playlist есть клипы.

**Действия и реакции.**
1. **Перемещение**: ЛКМ-drag клипа (в Draw/Paint). Alt — без snap [A].
2. **Копия**: отпустить мышь, затем **Shift+клик-и-drag** — копия следует за курсором [A]. Shift+клик по клипу — клон на место [A].
3. **Дублирование вправо**: выделить, **Ctrl+B**; шаг повтора задаётся выделением области времени (Ctrl+drag по линейке тактов), а не выделением клипов [A].
4. **Разрез**: инструмент **Slice (C)** — вертикальный драг; Left-Shift — диагональный разрез; Right-Shift+клик — без драга [A].
5. **Обрезка краёв**: Shift+drag за начало/конец клипа — «окно» двигается, данные сохраняются [A]. Аудио: Shift+M — режим stretch (край растягивает звук) [A].
6. **Slip (S)**: сдвиг содержимого внутри границ [A].
7. **Удаление**: ПКМ по клипу (в Draw/Paint), инструмент Delete (D), или Del по выделению [A].
8. **Mute без удаления**: инструмент T [A].
9. **Удаление/вставка времени**: Ctrl+Del / Ctrl+Ins по выделению времени — вся правая часть сдвигается [A].

**Изменения данных.** Операции меняют только экземпляры клипов {позиция, окно, mute}; источники (паттерны/сэмплы) не затрагиваются, кроме Make unique / Make unique as sample [A].

**Особые случаи.** Merge pattern clips (Ctrl+G) склеивает соседние клипы одного источника; Make unique нужен перед независимым редактированием «копии» [A]. Группировка клипов Shift+G — двигаются вместе [A].

## Сценарий 6. Добавление инструмента и загрузка сэмпла

**Исходное состояние.** Проект открыт; Channel Rack виден (F6); Browser (Alt+F8) слева.

**Действия.**
1. **Инструмент**: «**+**» внизу rack → список favorites → выбор; либо Browser > Plugin database > Generators → drag на rack; либо Plugin Picker (F8) — двойной клик по иконке [A].
2. **Сэмпл**: в Browser ЛКМ по файлу — превью до 5 сек; **drag файла в rack** — создан Sampler-канал (drag в **Playlist** дал бы Audio Clip!) [A].
3. **Замена**: ПКМ по каналу → Replace (или просто перетащить новый сэмпл на канал) [A/B].
4. Горячая подмена: выбрать канал, в Browser **Shift+↑/↓** — перебор сэмплов папки на слух [A].

**Реакция интерфейса.** Новый ряд в rack; открылся Channel Settings + GUI плагина (следующий клик по другой кнопке закроет предыдущий GUI, если включено Auto select linked modules) [A].

**Изменения данных.** В проекте: канал {тип, плагин/сэмпл, параметры, mixer-назначение=Master} [A].

**Результат.** Инструмент готов к программированию.

**Особые случаи.** Кнопка «+» показывает только **favorites**; полный список — More plugins… (чекбокс = favorite) [A]. Не забытые VST подхватываются через Manage plugins > Start scan + Verify [A/PDF]. Alt при drop — добавить без открытия GUI [A].

## Сценарий 7. Добавление эффекта и цепочка обработки

**Исходное состояние.** Канал(-ы) маршрутизированы на mixer-трек (см. сценарий 8); Mixer открыт (F9).

**Действия.**
1. Выбрать трек (клик по fader/pan).
2. В панели справа (Track inspector) — список **10 FX-слотов**: клик по стрелке слота → favorites эффектов (или Plugin Picker) [A].
3. Эффект загружен: **клик по имени** — открыть/закрыть GUI; **LED** — bypass; колесо над слотом — переставить (порядок = порядок обработки: сигнал входит сверху) [A/PDF].
4. Построить цепочку, например EQ → Compressor → Limiter [B: типичные стоковые — Fruity Parametric EQ 2, Fruity Limiter, Reeverb 2, Delay 3].
5. Сохранить цепочку: Mixer menu > File > **Save mixer track state**; перетащить иконку состояния на другой трек — скопировать цепочку [A].

**Реакция интерфейса.** На треке оранжево светится индикатор FX; пик-метры реагируют; LED-переключение слышно сразу [A/PDF].

**Изменения данных.** Трек получил список слотов {плагин, состояние, bypass, mix level}; порядок = цепочка [A].

**Особые случаи.** FX слота больше 10 — Patcher или send на другой трек [A]. Байпас целого трека — клик по FX-иконке трека [A/PDF].

## Сценарий 8. Маршрутизация канала в Mixer

**Исходное состояние.** Каналы играют в Master («---»).

**Действия.**
1. Быстро: выделить каналы в rack → **Ctrl+L** — «расселить» по свободным mixer-трекам с автоименами [A]. Ctrl+Shift+L — последовательно с выбранного трека [A].
2. Вручную: селектор mixer-трека в строке канала (Alt+M — показать/скрыть) — вертикальный драг на номер [A]. Или в Channel Settings: клик по слову TRACK — auto-assign первого свободного [A/PDF].
3. Send между треками: выбрать трек-источник, **клик по send-переключателю** внизу трека-приёмника; появится ручка уровня [A].
4. **Sidechain**: ПКМ по send-переключателю → Sidechain only (send уровня 0; слышимого сигнала нет, сигнал видит плагин-приёмник) [A].
5. Подмикс: выделить треки → Track routing > **Create submix** [A].

**Реакция интерфейса.** Send-переключатель зелёный, ручка уровня активна; View > Routing cables рисует кабели; петли блокируются серыми переключателями [A].

**Изменения данных.** Канал: mixer = N (один!). Аудио-граф: send {from→to, level} [A].

**Особые случаи.** Playlist-треки в маршрутизации **не участвуют** [A]. Pre-fader send — только через плагин Fruity Send [A].

## Сценарий 9. Создание и редактирование автоматизации

**Исходное состояние.** Играющий проект; есть параметр (например, Volume аудиоклипа или фильтр синта).

**Действия.**
1. **ПКМ по параметру** → **Create automation clip** — в Playlist на первом свободном треке появляется клип-линия; стартовое значение фиксируется как Initialized control [A].
2. Для VST: покрутить ручку плагина → ADD > **Automation from last tweaked** [A].
3. Редактирование: ПКМ по линии — точка; drag точки; ПКМ по правой точке сегмента — тип кривой (линия/кривые/**Hold**/Stairs/Pulse/Wave…); Alt — без snap; правый Alt+клик — удалить точку [A].
4. Край клипа — растянуть; скопировать — как обычный клип [A].
5. LFO поверх: Channel settings клипа > LFO Mode [A].
6. Альтернативный путь (event-автоматизация): правый клик по Record → фильтр **Automation**; Record + Play; двигать крутилку — события пишутся в **текущий паттерн**; просмотр/правка — ПКМ по параметру → Edit events; конвертация — Turn into automation clip [A].

**Реакция интерфейса.** Параметр двигается сам при воспроизведении; в Pattern Clip event-автоматизация видна розовой тенью; Automation Clip — графиком [A].

**Изменения данных.** Automation Clip = новый генератор-канал с огибающей (не привязан к паттерну); event-данные живут в паттерне [A].

**Особые случаи.** Записанная live-автоматизация перекрывает ручное значение параметра — «ручка больше не подчиняется напрямую» [A/PDF]. Если перед созданием клипа выделить область времени — клип ограничится ей [A/PDF].

## Сценарий 10. Запись и редактирование MIDI

**Исходное состояние.** MIDI-клавиатура подключена и включена в OPTIONS > MIDI settings (F10); выбран канал-инструмент; PAT mode.

**Действия.**
1. ПКМ по **Record** → фильтр: **Notes** (заодно можно Automation/Audio) [A].
2. Опции: Count-in (Ctrl+P), Metronome (Ctrl+M), Blend record (Ctrl+B — примешивать вместо перезаписи), Loop record [A].
3. **R** → Play: играть партию. Ноты пишутся в **выбранный канал текущего паттерна** (Piano roll канала). В SONG mode — в паттерн, а клип автоматически вставляется в Playlist в точке старта [A].
4. Квантизация ввода: Global Snap Step/Beat/Bar — включена; Line/Cell/none — выключена; доп. опции в меню кнопки Record (start/end/duration) [A].
5. После записи — правка в Piano Roll (Quantize Alt+Q и др.) [A].
6. **Спасение импровизации без записи**: Score Logger всегда буферизует 3 минуты ввода; Tools > **Dump score log to selected pattern** [A].
7. Запись с клавиатуры ПК: Ctrl+T (Typing keyboard to piano) — буквы = ноты [A]. Пошаговый ввод: Step edit (Ctrl+E) — каждая клавиша ставит ноту и сдвигает позицию [A].

**Реакция интерфейса.** playhead бежит, ноты появляются в ролле; Score logger работает всегда (невидим) [A].

**Изменения данных.** Паттерн получил ноты; при Song mode — новый/переиспользованный клип в позиции старта [A].

**Особые случаи.** Пока Typing to piano включён, одиночные буквенные хоткеи редакторов не работают [A]. Отмена записи — Undo или Help > Cancel Current Recording (удаление аудио-файлов при undo — безвозвратно) [A].

## Сценарий 11. Выделение, копирование, вставка, отмена

**Исходное состояние.** Любой редактор (Piano Roll / Playlist).

**Действия и реакции.**
1. **Выделение**: Ctrl+ЛКМ-drag — прямоугольник; Shift+клик — добавить/убрать; Ctrl+A / Ctrl+D / Shift+I (инверт); по цвету Shift+C; время — Ctrl+drag по линейке (Playlist) [A].
2. **Копирование**: Ctrl+C; вставка Ctrl+V (Piano roll — от левого видимого такта) [A]; в рамках мыши: Shift+drag — копия [A].
3. **Дублирование**: Ctrl+B — вправо от выделения (ноты и клипы) [A].
4. **Вырезание/удаление**: Ctrl+X / Del; удаление времени Ctrl+Del, вставка Ctrl+Ins [A].
5. **Отмена**: Ctrl+Z — последний; Ctrl+Alt+Z — шаг назад по истории; полная история — Browser > Current project > History (клик = откат к состоянию) [A].

**Особые случаи.** Буфер обмена «состязателен»: Piano Roll имеет отдельный MIDI-clipboard (Shift+Ctrl+V) для обмена с другими программами [A]. Cut/Copy в EDIT-меню работают для выделенных каналов (Step Sequencer), но **не для event-автоматизации** [A].

## Сценарий 12. Сохранение и повторное открытие проекта

**Действия.**
1. **Ctrl+S** — Save; при первом сохранении — диалог имени/папки [A]. **Ctrl+Shift+S** — Save as; **Ctrl+N** — Save new version (MyProj_2, MyProj_3…) [A].
2. Для переноса: Save as → тип **Zipped loop package** (.zip = .flp + все сэмплы) — FL открывает его напрямую [A].
3. Доп. формы: Project bones (пресеты/скоры/автоматизация), Project data files (все файлы в одну папку), Export > All playlist tracks (стемы) [A].
4. Повторное открытие: File > Open, drag .flp на рабочий стол, Recent files (Alt+1..0), или через Browser > Projects (ПКМ > Open) [A/PDF].
5. Восстановление: Revert to last backup; автобэкапы в File settings [A].

**Реакция интерфейса.** Имя проекта в Title bar; при наличии несохранённых изменений — диалог при New/Exit [A]; demo-плагины предупреждают при сохранении и заменяются заглушками без лицензии [A].

**Изменения данных.** .flp содержит: каналы, паттерны, аранжировку, mixer-граф, автоматизацию, настройки проекта — но **не сэмплы** (абсолютные пути) [A].

**Особые случаи.** Потерянные сэмплы (файл перемещён) — кнопки каналов краснеют; FL грузит только wav/mp3/ogg [A]. Открыв чужой .flp без сэмплов — сначала Zipped loop package от автора [A/B].

## Типовой сквозной цикл (синтез гайдов) [A/B]

Шаблон → задать BPM → ударный паттерн (шаги) → мелодия/бас в Piano Roll (отдельные паттерны) → раскладка секций в Playlist (F4, Ctrl+B, маркеры Ctrl+T) → маршрутизация (Ctrl+L) → эффекты (EQ/comp/reverb/limiter) → автоматизация (rights-click → Create automation clip) → запись MIDI/аудио по необходимости → экспорт (Ctrl+R WAV / Ctrl+Shift+R MP3; SONG mode; Tail=Leave) → сохранение (Ctrl+S; шаринг — Zipped loop package).
