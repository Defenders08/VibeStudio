**Дата:** 2026-10-20. **Контекст:** `crates/flp_compat` (парсер FLP, 29 тестов) + `apps/proto-ui` (FL-скин, иконки, UX по мануалу) готовы; звук/сохранение — заглушки.

## A. Общая стратегия интерфейса

**1. Степень сходства с FL Studio** — определяет весь дальнейший UI.
- а) Максимальный клон: внешний вид и поведение 1:1, чтобы пользователь FL чувствовал себя дома
- б) FL-подобный: та же логика окон/тулбара/шагов, но дизайн свой (текущая точка)
- в) Свой интерфейс: берём из FL только лучшее (step-sequencer, piano roll), остальное — оригинальное
- г) Сначала клон для прототипа → постепенное расхождение в собственный стиль

**2. Кто первый пользователь интерфейса?**
- а) Ты сам (главный сценарий — твоя работа)
- б) Публичный продукт с первого релиза (нужны онбординг, дефолты «для новичка»)
- в) Оба, но приоритет — твоё удобство

**3. Тема оформления:**
- а) Только точная копия FL Platinum (как сейчас)
- б) FL-подобная + позже переключатель тем (тёмная/светлая/акценты)
- в) Собственная фирменная тема (свой характер, не FL)

**4. Разрешение/масштаб:** на каком экране в основном будешь работать? (MacBook 14"? внешний 27"+? несколько мониторов?) Нужен ли zoom интерфейса (в FL — Ctrl+колесо по тулбару)?

## B. Раскладка и окна

**5. Модель окон:**
- а) Как в FL: плавающие окна со сцеплением (drag к краю — прилипание), «стол» с обоями
- б) Жёсткий докинг: панели прикованы к краям, как в Ableton/Bitwig
- в) Гибрид: Browser/Rack прикованы (как сейчас), Playlist/Roll/Mixer плавают

**6. Дефолтная раскладка при старте** (что открыто сразу)?
- а) Как сейчас: Browser + Rack + Playlist
- б) Всё главное: Browser + Rack + Playlist + Piano Roll + Mixer
- в) Минимализм: только Rack + Browser (Piano Roll по F7)
- г) Как в FL «Default»: Rack + Playlist + Browser

**7. Browser:** оставить прикованным слева (сейчас) или сделать плавающим окном как в FL? Нужен ли поиск (Ctrl+F) в первой версии?

**8. Заголовки плавающих окон:** добавить тонкую полосу-«шапку» в стиле FL с меню-якорем (▾) в каждом окне? (Сейчас меню только у Playlist.)

## C. Piano Roll

**9. Что докрутить следующим?** (можно несколько, в порядке важности)
- а) Выделение рамкой (E) + Shift-добавление
- б) Shift+drag = копия ноты
- в) Растяжение группы нот (stretch-хэндл выделения)
- г) Двойной клик = окно свойств ноты (как в FL)
- д) Слайд-ноты (S) визуально
- е) Ghost notes редактируемые (Alt+V)
- ж) Подсветка гаммы/тоники на фоне (scale highlighting)

**10. Панель свойств внизу ролла:** сейчас там velocity. В FL она переключается (Target: Velocity/Pan/Release/Mod X/Mod Y/Pitch). Сделать переключатель сразу?
- а) Да, все шесть целей (данные ноты уже есть в NoteRecord: pan/release/fine_pitch)
- б) Только Velocity + Pan
- в) Оставить только Velocity

**11. Цвет ноты:**
- а) По цвету канала-владельца (как сейчас)
- б) 16 цветов = MIDI-каналы (как в FL, shift+C выделение по цвету)
- в) По velocity (тепловая карта)

**12. Клавиатура слева:** добавить превью-звук при клике на клавишу (когда появится движок) и зум колёсиком? Приоритетно?
